# Sky Guide

Constellation stories from seven cultures, science facts, a sky calendar and a tour planner, in English and Arabic.

Made by Yousef Abdulfattah, Astronomy-Specialist, from Saudi Arabia. Generated with AI (Claude, by Anthropic).

Live site: https://yousef-ay12.github.io/SkyGuide/

The readable code is in [`source/`](source/): the page, styling, code and data, and `build.py`, which builds the site files here (`index.html`, `assets/`, `sw.js`).
